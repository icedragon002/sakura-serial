## 引脚分配

| ESP32-S3 引脚 | 功能 | 连接目标 |
|---------------|------|---------|
| GPIO19/20 | USB D-/D+ | PC (CDC) |
| GPIO4/5 | I²C0 SDA/SCL | 外部 I²C 设备 |
| GPIO6/7/8/10 | SPI1 MOSI/MISO/SCK/CS0 | RP2350 LA 数据 |
| GPIO11/12/13 | SPI2 | 外部 SPI 设备 |
| GPIO17/18 | UART1 RX/TX | 外部 UART 设备 |
| GPIO14/15/16/21 | CAN TX/RX + 1-Wire | MCP2551 + DS18B20 |
| GPIO0-3, 38-41 | GPIO | 自由使用 |

| RP2350 引脚 | 功能 | 连接目标 |
|-------------|------|---------|
| GPIO0-7 | PIO LA CH0-7 | 8 通道逻辑分析输入 |
| GPIO8-11 | SPI0 (从机) | ESP32-S3 SPI1 |
| GPIO12 | 触发输入 | 外部触发源 |

## 数据流

```
[被测设备] ──I²C/SPI/UART/CAN/1-Wire/GPIO──► ESP32-S3 ──帧协议──► PC App
[被测信号] ──8ch 并行────► RP2350 PIO ──SPI──► ESP32-S3 ──帧协议──► PC App

PC App ──帧协议──► ESP32-S3 ──SPI──► RP2350 (配置采样率/触发/启停)
```
